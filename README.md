# Student Placement Predictor & Skill Gap Analyzer

A portfolio-ready ML project using the public **Placement Prediction Dataset**.

Dataset source: Kaggle — Ruchika Kumbhar, *Placement Prediction Dataset*.
https://www.kaggle.com/datasets/ruchikakumbhar/placement-prediction-dataset

The Kaggle dataset page lists the dataset as **CC0: Public Domain** and describes academic, training and placement-status fields including CGPA, internships, projects, workshops/certifications, aptitude score, soft skills, extracurricular activities, placement training, SSC/HSC marks and placement status.

## Run the whole project

1. Keep the project folder together.
2. Double-click **START_PROJECT.bat**.
3. It installs Python packages, downloads the public dataset, extracts it, trains two classifiers, chooses the better F1 model, and launches the Streamlit app.

No manual CSV placement is required.

## Models

- Logistic Regression
- Random Forest
- Accuracy
- Precision
- Recall
- F1-score

## Important

The model is for educational/portfolio use. Its probability is not a guaranteed placement probability and should not be presented as a real hiring decision.

## Resume-ready description

**Student Placement Predictor & Skill Gap Analyzer** — Developed an end-to-end machine learning application using a public placement dataset; implemented preprocessing, categorical encoding, Logistic Regression and Random Forest classification, model evaluation, and a Streamlit dashboard for placement prediction and personalized skill-gap recommendations.
